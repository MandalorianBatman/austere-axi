Decision: pick two to shortlist

Which two vector databases should we shortlist?

Use case: semantic search over 40M document chunks, 768-dim embeddings, p95 query latency target 50 ms. Latency figures come from our own test at 40M.

Our recommendation: Qdrant + Pinecone

Qdrant has the best latency per dollar (44 ms at $1,250/mo). Pinecone has the lowest latency (38 ms) and no ops burden. Change the shortlist below if you disagree.

p95 latency vs. the 50 ms target

50 ms target. Only Pinecone and Qdrant meet it; Milvus misses by 2 ms and Weaviate by 11 ms.

Key tradeoffs

Pinecone

Win: lowest latency (38 ms), managed only so no ops.

Cost: highest price ($3,100/mo) and proprietary license.

Weaviate

Win: managed or self-host, hybrid search, BSD-3.

Cost: slowest (61 ms), misses the 50 ms target.

Qdrant

Win: lowest cost ($1,250/mo), 44 ms, very good filtering, Apache-2.0.

Cost: none flagged in the data provided.

Milvus

Win: Apache-2.0, low sticker price ($1,400/mo).

Cost: 52 ms misses target, partial hybrid search, self-host means added ops time.
