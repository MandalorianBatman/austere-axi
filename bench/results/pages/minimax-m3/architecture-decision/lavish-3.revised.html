Architecture decision review

ADR-017 — Event bus for order events

Review the proposed event-driven replacement for synchronous order processing.

Proposed

Context

The Orders service calls Billing, Shipping and Notifications over HTTP in sequence. One slow call blocks checkout. Last quarter there were 3 incidents from this.

Problem

Sequential HTTP calls make checkout latency dependent on the slowest downstream service.

Proposed decision

SQS + SNS

Orders publishes order.placed to an SNS topic. Billing, Shipping and Notifications each read from their own SQS queue.

Managed Independent consumers No event replay
