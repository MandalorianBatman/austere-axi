ADR-017

Event bus for order events

Review the proposed move from sequential HTTP calls to an event-driven order flow.

Decision status

Proposed

Awaiting reviewer action

Why this decision

Current context

The Orders service calls Billing, Shipping and Notifications over HTTP in sequence. One slow call blocks checkout.

3 incidents from this occurred last quarter.

Proposed decision

SQS + SNS

Orders publishes order.placed to an SNS topic. Billing, Shipping and Notifications each read from their own SQS queue.
